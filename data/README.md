# Dados narrativos

Os arquivos desta pasta descrevem conteúdo, não comportamento.

- `objects.json`: objetos e pontos de interação.
- `dialogues.json`: textos narrativos estáticos.
- `choices.json`: rótulos e estrutura das escolhas.
- `memories.json`: configuração das memórias e retornos.
- `rooms.json`: conexões entre os ambientes.

Evite inserir JavaScript dentro dos JSONs. Uma ação deve possuir um ID ou ser ligada pelo código da cena/sistema correspondente.
