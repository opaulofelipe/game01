# A Casa — reconstrução v2

Esta pasta é a nova base jogável.

## Regra principal

Nada dentro de `src/` deve ser usado como base visual ou física para a reconstrução.

A versão anterior permanece na branch `main` apenas como referência histórica.

## O que pode ser reaproveitado

- roteiro;
- estrutura narrativa;
- diálogos;
- memórias;
- lista de objetos;
- escolhas;
- nomes e relações entre personagens.

Os dados narrativos originais permanecem em `/data` e podem ser migrados seletivamente conforme cada cena nova for aprovada.

## O que deve ser reconstruído

- movimentação;
- sprites;
- colisões;
- mapas;
- portas;
- interações;
- tutorial;
- HUD;
- áudio;
- iluminação;
- cenas;
- responsividade;
- acessibilidade visual;
- organização física dos cômodos.

## Critério de avanço

Nenhuma etapa é considerada pronta porque existe código para ela.

Ela só é concluída quando funciona visualmente e fisicamente em jogo e passa por teste prático.
